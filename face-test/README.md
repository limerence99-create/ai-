\# AI 创作平台（类 RunningHub）- 面试考核项目



\## 🏗 系统架构

\- \*\*前端\*\*：React 18 + Vite + TailwindCSS + React Router

\- \*\*后端\*\*：Node.js + Express + JSON 文件存储

\- \*\*认证\*\*：JWT + bcrypt

\- \*\*代理\*\*：Vite 内置代理 /api → localhost:3001

\- \[x] 用户注册/登录/个人中心

\- \[x] 模型库（类型筛选、搜索）
