# ai-
AI创作平台（类RunningHub）轻量级AI内容聚合平台，支持工作流浏览、作品展示与模型下载。 技术栈：React 18+Vite+TailwindCSS｜Node.js+Express+JWT｜JSON存储（易迁库） 功能：用户鉴权、工作流市场（搜索/分类）、作品广场（点赞/浏览）、模型库、响应式UI 启动： 1. cd backend &amp;&amp; node server.js 2. cd frontend &amp;&amp; npx vite --port 3002 3. cd backend &amp;&amp; node seed.js 4. 访问 http://localhost:3002 模块化架构、2小时MVP、AI辅助开发、开箱即用。
